# Idea-Book

> A creative space for capturing and managing ideas.

## 📖 Overview
A frontend web application built with React and Vite for fast, modern web development.

## 🛠️ Built With
* **Framework:** React `18.2.0`
* **Build Tool:** Vite `5.1.0`

## 🚀 Getting Started

### Prerequisites
* Node.js (v16 or higher)
* npm or yarn

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/mohitshukla02/Idea-Book.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```
